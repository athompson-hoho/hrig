# Project and panel navigation

Open a project with Ctrl+O (Cmd+O on macOS). The project hub lists attached rig folders, recent folders and favorites, with host and rig labels. Search, pin or remove history entries, browse a folder, or enter a path. Removing history never deletes files or rigs.

History retains up to 50 favorites and 50 recent projects. Entries are tied to the saved connection and endpoint; removed or retargeted connections appear unavailable. HRig validates a folder before switching and preserves the current project when validation fails or the dialog is canceled. Layouts remain associated with their existing project path. History stores folder/host metadata, not file contents or credentials.

Ctrl+P (Cmd+P) opens fuzzy project-file search. Type a filename or path subsequence, optionally followed by `:line`; use arrows and Enter to open a result. Local, WSL and SSH connections use the same ranking. Traversal is bounded to 20,000 entries and 25 levels, excludes generated directories and symbolic links, and returns the best 100 matches found. Partial and limited scans are explicitly labeled. Existing file confinement and size limits still apply. Superseded results are discarded; dismissing the dialog does not terminate an already-running remote read.

Ctrl+Shift+P (Cmd+Shift+P) finds existing panels in the current workspace by title, file, rig, seat, host or group. Recent panels appear first. Selecting a result focuses its docked panel, floating panel or native popout without opening another copy. The navigator also offers move-to-group and split controls, including Alt+Left/Right/Down/Enter. Rename groups in Arrange workspace; moves, splits and group names participate in arrangement undo.

Project path spelling remains stable to preserve previous layout keys. Different aliases for the same remote folder can remain separate entries. Existing content search remains literal; regex, whole-word and include/exclude content filters are future HR-16 work.

Seat rows and the command center offer Open seat beside current. This reuses an existing seat panel and puts it to the right of the active group. See [terminal splits](docs/terminal-splits.md) for behavior and existing arrange/navigator controls.

The command center (Ctrl+K, Cmd+K on macOS) also runs Toggle sidebar, Toggle status bar, Refresh rigs and workspace and Open welcome guide; Toggle status bar flips the appearance.statusBar setting, so the same entry turns it back on. Typing several words keeps only the commands whose name or hint contains every word, lists name matches before hint-only matches, and Enter runs the first command in that list. These commands only change what is shown or re-read data and none sends anything to a terminal or seat.

With an empty query, Quick Open lists the files you opened most recently in this project under Recent files, newest first; arrows and Enter reopen one, and typing switches to the normal search while clearing the query brings the recents back. HRig keeps up to 20 project-relative paths per project in the workspace file (paths only, never file contents), and forgets a path when opening it fails. The panel navigator likewise lists open panels most recently focused first while its query is empty. Choosing an entry only opens the file or focuses the panel and sends nothing to a terminal or seat.

The Welcome screen lists up to five of your pinned and most recently opened projects under Continue where you left off, pinned ones first and marked with a star; with no history the section is not shown. Click a project to open it exactly as the project hub does: the Open a project dialog appears while HRig checks the folder, closes once the project is open and stays up with the error if the check fails. An entry whose connection was removed or retargeted is shown as unavailable and cannot be opened. Opening a project only switches folders and sends nothing to a terminal or seat; pin, unpin and remove stay in the project hub.

Press ? when focus is not in a text field, the editor or a terminal to open the Keyboard shortcuts sheet, a read-only list of the app, terminal and editor shortcuts with Cmd or Ctrl labels for your platform; Escape, ? again or a click outside closes it. The command center entry Open keyboard shortcuts opens the same sheet, and the welcome guide and Settings point to it. The sheet sends nothing to a terminal or seat, and a ? typed into a field, the editor, a terminal or while a dialog is open is left alone.

The command center entry Reopen closed panel, or Ctrl+Shift+H (Cmd+Shift+H on macOS), reopens the file, diff or seat panel you closed most recently in the current workspace. HRig remembers up to 10 closed panels, in memory only, so they are forgotten when the app restarts. Each is kept as its kind plus the project, path or seat identifiers needed to open it again, never file contents, terminal output or commands, and closing the same panel twice keeps only the newest copy. A file or diff reopens exactly as if you had chosen it in Quick Open or the sidebar, so a deleted file shows the usual error and edits you discarded when closing are not restored. A seat reopens through Open seat, which attaches to the seat's existing session: it never launches, relaunches or restarts an agent, and nothing is typed or sent. Shells, rig-control terminals, settings and tool panels are not remembered, because closing a shell ends it and a reopen would start something new; Ctrl+Shift+T (Cmd+Shift+T) still opens a new shell. When the seat is gone or the connection has changed, a short message says why, and a seat that only needs a refresh stays in the list. With nothing to reopen the command shows Nothing to reopen. The shortcut is ignored while a dialog is open and does not repeat while held, and in a terminal it replaces Ctrl+Shift+H, which no longer reaches the shell.

Double-click the empty part of a panel group's tab strip, press Ctrl+Shift+M (Cmd+Shift+M on macOS), or choose Maximize panel in the command center to make that group fill the workspace. The other groups are hidden, not closed: their terminals keep running and every tab, size and arrangement is kept exactly as it was, so double-clicking the strip again, pressing the same shortcut or choosing Restore panel layout brings back the previous layout. Double-clicking a tab still renames it, and the maximize button in the group's toolbar works as before. Escape never restores, because editors and terminals need it. With only one group open there is nothing to hide, and a short message says so. Maximized is a view state for the current session and is not saved with the layout: after a restart, when you switch projects and come back, or when you apply a saved or role layout, every group is visible again. A new panel opens in the maximized group, a panel that is already open in a hidden group is only selected there until you restore the layout, and Find open panels restores the layout first when you pick a panel in a hidden group. The shortcut is ignored while a dialog is open and does not repeat while held, and in a terminal it replaces Ctrl+Shift+M, which no longer reaches the shell; plain Ctrl+M, including Monaco's Tab key moves focus toggle in the editor, is unchanged. Terminals in the visible group are refitted by the normal resize path and terminals in hidden groups are left alone; nothing is typed or sent.
