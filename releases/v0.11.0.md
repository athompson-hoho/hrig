# HRig 0.11.0 - Project hub and faster navigation

## New

- Search recent and favorite projects with host and rig labels, pin/remove history, and validate folders before switching.
- Fuzzy Quick Open with Ctrl+P/Cmd+P, keyboard selection and optional :line navigation across local, WSL and SSH projects.
- Find existing panels with Ctrl+Shift+P/Cmd+Shift+P, recent-first ordering and focus for native popouts.
- Name groups and move/split panels with keyboard controls and arrangement undo.
- Preserve unsaved buffers and existing shell sessions while navigating projects.

## Validation

Production compilation, all 31 desktop journeys and all 36 applicable backend checks pass (one Unix-only check skipped). Windows packaged smoke, update-feed verification and all three navigation journeys against the packaged executable also passed. Cross-platform release evidence is recorded by the native workflow. Navigation journeys cover disposable real shells, unsaved drafts, favorites across restart, invalid folders, stale responses, group undo and native popout focus.

## Known limitations

Quick Open scans at most 20,000 entries and 25 levels and returns up to 100 ranked results, with explicit partial/limited indicators. Panel search covers the current workspace. Advanced content-search filters remain on the roadmap. Signing credentials remain deferred; downloads are unsigned and macOS is not notarized. Real SSH deployment behavior still depends on the configured remote environment.

## Install or upgrade

Use Windows setup or portable EXE; macOS DMG/ZIP for your architecture; or Linux AppImage, tar.gz, DEB or RPM. Settings > Updates opens manual downloads. Verify downloads against SHA256SUMS. Existing settings, project layouts and recoverable drafts are retained.
