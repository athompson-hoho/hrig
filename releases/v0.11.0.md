# HRig 0.11.0 - Account-aware teams and faster navigation

## New

- Search recent and favorite projects with host and rig labels, pin/remove history, and validate folders before switching.
- Fuzzy Quick Open with Ctrl+P/Cmd+P, keyboard selection and optional :line navigation across local, WSL and SSH projects.
- Find existing panels with Ctrl+Shift+P/Cmd+Shift+P, recent-first ordering and focus for native popouts.
- Name groups and move/split panels with keyboard controls and arrangement undo.
- Preserve unsaved buffers and existing shell sessions while navigating projects.

## Rig design and accounts

- Make the project goal optional, with an editable work-type suggestion.
- Recommend seat runtimes from Codex and Claude Code sign-ins confirmed on the selected host; keep manual per-seat overrides.
- Show host-scoped runtime authentication and read-only Orca-managed account metadata in the status bar and wizard. Windows profiles do not establish WSL or SSH access.
- Assess teams directly with supported providers or through a portable prompt, compare lean/balanced/throughput options, preserve manual seat edits, and define explicit first handoffs. Assessment runs are explicit and may consume model usage.
- Add an OpenRig control center with installed-help forms, command explanations, structured results and exact single-use action reviews. Interactive commands open terminal panels. Interface coverage is not proof every CLI operation succeeds.
- Correct Unicode input decoding in the remote Quick Open scanner on Windows.

## Known limitations

Quick Open scans at most 20,000 entries and 25 levels and returns up to 100 ranked results, with explicit partial/limited indicators. Panel search covers the current workspace. Advanced content-search filters remain on the roadmap. Signing credentials remain deferred; downloads are unsigned and macOS is not notarized. Real SSH deployment behavior still depends on the configured remote environment. Managed account profiles are informational; account switching and per-seat account binding are not implemented. Context-window usage, rate limits and quota are not inferred from authentication. Auto runtime selection does not guarantee model access or concurrent-seat capacity. See docs/ACCOUNTS.md and docs/CLI-GUI-COVERAGE.md.

## Install or upgrade

Use Windows setup or portable EXE; macOS DMG/ZIP for your architecture; or Linux AppImage, tar.gz, DEB or RPM. Settings > Updates opens manual downloads. Verify downloads against SHA256SUMS. Existing settings, project layouts and recoverable drafts are retained.
