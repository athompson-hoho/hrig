# HRig 0.6.2 - Rig designer aligned with the workspace

## Appearance

The rig wizard now follows HRig's existing tool-panel styling and density.

- Replaced the separate Rig Studio branding and promotional header with a compact Rig designer heading.
- Removed the large rounded outer frame, gradient backgrounds, shadows, and oversized badges.
- Uses the workspace's panel/surface colors, border tones, mint accents, shared inputs and buttons, and smaller typography.
- Compact step tabs indicate progress without a large navigation banner.
- Project name and goal share a row on wider panels, while settings and seat layouts collapse on narrower panels.
- Work-type and team-size choices use smaller icons, tighter spacing, and restrained selection states.
- Seat and review panels use the same simple borders and row treatments as the rest of the workspace.
- Preview results, warnings, and typed launch/deletion confirmations remain available.

## Validation

TypeScript/Vite build, the isolated Electron designer journey, wide/narrow screenshot review, and packaged Windows smoke test verify this desktop update. The journey covers selection, design revision, preview, typed launch confirmation, and deletion confirmation. Live user rigs remain untouched. Desktop builds exclude concurrent mobile work.

## Known limitations

Recommendations still match installed agent role names and require explicit choices where no match exists. The goal is the rig summary; assign tasks after launch. Agent references depend on the selected host's library. SSH deployment and OS notification validation remain as documented in earlier releases. This update changes presentation rather than adding IDE extensions or debugging.

## Install or upgrade

Download **HRig.0.6.2.exe** from this release's assets on Windows x64. Close the current HRig instance before opening the portable executable. Saved connections and layouts remain in the HRig application-data directory. WSL/SSH hosts require Linux Node, OpenRig, tmux and Python 3. The executable remains unsigned.

## Integrity and source

Use the attached **HRig-0.6.2-SHA256SUMS.txt** to verify the executable with PowerShell: Get-FileHash -Algorithm SHA256 -LiteralPath './HRig.0.6.2.exe'. The source tag contains the desktop implementation and release notes. The portable executable is attached as a release asset.
