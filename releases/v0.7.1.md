# HRig 0.7.1 - Community themes

## New palettes

Eight community adaptations join the five built-in palettes: Catppuccin Mocha, Macchiato, Frappe and Latte; Nord; Dracula Classic; Tokyo Night; and Gruvbox Dark. Choose them under Settings > Appearance. Follow Windows remains available.

- Separate built-in/community preview groups show syntax-color swatches.
- Theme default accent uses each palette's native color. Existing explicit accent overrides remain intact.
- Core workspace/editor surfaces preserve source palette anchors, with derived secondary workspace shades and readable secondary UI text.
- Editors receive theme-specific comment, string, keyword, number, type, function and variable token rules where supported by Monaco's tokenizer. These are palette adaptations, not full VS Code extensions or semantic language-server themes.
- Terminals receive all 16 normal/bright ANSI colors. Any bundled palette can be selected independently from the application theme, with legacy dark/light settings retained.
- User and project scope, settings JSON transfer, persistence, detached-window theme updates and live terminal sessions continue to work.
- Theme names are included in settings search matching.

## Validation

Palette checks cover official color anchors, syntax rules, all 16 ANSI colors, native accents, import validation and secondary UI contrast. Electron journeys switch all eight palettes, verify editor and terminal backgrounds, preserve a shell variable across changes, check independent terminal selection, update popouts, reset project overrides and retain explicit accents after restart. Production build, broader desktop regressions, packaged Windows smoke tests and license-asset checks verify the release. Live user rigs remain untouched.

## Known limitations

These are HRig palette adaptations rather than complete community editor extensions. Monaco token support varies by language, and application-specific true-color terminal output can choose its own colors. Fonts are unchanged and must be installed separately if desired. External theme-file/marketplace import is still a follow-up feature. Project appearance follows the active workspace.

## Install or upgrade

Download **HRig.0.7.1.exe** for Windows x64. Close the running HRig instance before launching the portable update. Saved connections, layouts and preferences are retained. WSL/SSH hosts still require Linux Node, OpenRig, tmux and Python 3. The executable is unsigned.

## Integrity and source

Verify the executable with **HRig-0.7.1-SHA256SUMS.txt** using PowerShell Get-FileHash -Algorithm SHA256 -LiteralPath './HRig.0.7.1.exe'. Source, palette provenance and full notes are available under this release tag. The executable is a release asset.
