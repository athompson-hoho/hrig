# HRig 0.12.0 - Update from the app

## New

- Packaged HRig checks for stable updates 10 seconds after startup and every six hours.
- A newer release prompts with release notes and a per-version Remind me tomorrow option. New versions bypass a reminder for an older version.
- Windows can download, verify and install updates from the prompt or Settings > Updates, including currently unsigned builds.
- Installation remains separate from downloading. Restart requires confirmation, unsigned-update acknowledgment when applicable, saved/discarded editor changes and successful workspace persistence.
- Portable Windows copies open per-user setup to move to an installed app. The original portable file remains. Portable launch flags are removed before starting setup.
- Signed builds retain signature verification. Downloads remain architecture-specific and checksum-verified; no automatic download, silent install or install-on-quit.

- Load status-bar account details on demand to avoid unnecessary runtime authentication probes during workspace startup and shutdown.

## Validation

Production compilation, backend updater/consent/scheduler tests, desktop prompt/snooze/confirmation and dirty-buffer guard journeys, plus a real read-only download of the published Windows installer with checksum verification. The download check never launches setup. Full desktop regression and native runtime/feed/package/installer/performance checks gate publication; matching native evidence is attached.

## Known limitations

Signing credentials remain deferred. Unsigned Windows updates verify download integrity but not publisher identity; Windows may display a security prompt. Unsigned macOS builds are not notarized and use manual downloads. Linux uses release downloads or its package manager. Context, account profiles and OpenRig runtime behavior are unchanged. Updating a portable copy does not overwrite the original portable executable. The first upgrade from 0.11.x or earlier must be installed manually to acquire the new updater.

## Install or upgrade

Windows x64: install the setup EXE, or run the portable EXE. To enable the new update system from older builds, download and install this version once; future Windows updates can be initiated inside HRig. macOS Apple Silicon/Intel: DMG or ZIP. Linux x64/ARM64: AppImage, archive, DEB or RPM. Verify assets with SHA256SUMS. Existing settings, layouts and recoverable drafts are preserved.

## Integrity and source

The version tag identifies immutable source. SHA256SUMS covers distribution/update assets and NATIVE-QA.json records native runtime, distribution and performance evidence. See DISTRIBUTION.md for update trust boundaries and restart behavior. Published artifact hashes and source are verified before release publication.
