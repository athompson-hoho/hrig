# HRig 0.6.0 - Guided rig design and deletion

## Guided rig designer

Open Manage rigs in the session sidebar or Tools > Rig manager, then choose Design a new rig.

- Three steps: needs, team, and review/launch.
- Work types include software development, research/planning, review/troubleshooting, and product/interface design.
- Solo, pair, and four-seat recommendations explain the usage and coordination tradeoffs.
- Installed agent role-name matching recommends seats; users choose agents explicitly for unmatched roles and can customize each seat name and runtime (Codex or Claude Code).
- Project selection includes live rig folders. Generated YAML-compatible JSON specs are saved as hrig-<name>.yaml in that project.
- Existing rigs and unrelated files are preserved. The wizard can revise its own saved design, detects external edits, and supports correction after a failed preflight.
- OpenRig validates and plans the design; a matching successful preview and typed rig name are required before launch.

## Rig deletion

Each rig has a Delete action with its ID and affected seats. Typed name confirmation is required. HRig rechecks the exact ID/name before asking OpenRig to stop managed seats, attempt a snapshot, and remove the record. Blocked or partial deletion is reported as a failure. Successful deletion of the selected rig returns to All rigs. The project folder and library specification are retained; the deleted rig record cannot be restored by name.

## Validation

Production build, twelve core/WSL checks, sixteen desktop journeys, visual review, and packaged Windows smoke test passed. A generated two-seat configuration passed installed OpenRig 0.6.14 plan/preflight without launching agents. Lifecycle tests used isolated fixtures; existing live rigs were untouched.

## Known limitations

Recommendations use installed agent names, not an AI design service. The goal becomes the rig summary; assign work after launch. Agent references are specific to the selected host's library. Runtime authentication and policy remain OpenRig's responsibility. Other earlier SSH, notification, and IDE limitations remain.

## Install or upgrade

Download **HRig 0.6.0.exe** from this release's assets on Windows x64. Close the running HRig instance before opening the new portable executable; existing user settings remain in the HRig application-data directory. WSL or SSH hosts need Linux Node, OpenRig, tmux, and Python 3. Connect the host in HRig; this application does not install an agent harness for you.

The executable is unsigned. Windows may show a publisher warning. Only run files obtained from this private repository.

## Integrity and source

The attached **HRig-0.6.0-SHA256SUMS.txt** contains the SHA-256 digest of the executable. Check it with PowerShell: Get-FileHash -Algorithm SHA256 -LiteralPath './HRig 0.6.0.exe'. The executable is a release asset, not part of the Git source archive.
