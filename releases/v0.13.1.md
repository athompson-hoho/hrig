# HRig 0.13.1 - Reliable Windows update feeds

## Fixed

Pin the native update channel in the app, including when installed app-update.yml omits it. Keep downgrade prevention enabled after channel selection. Publish a byte-identical latest.yml compatibility feed for older Windows x64 clients, and require it during packaging, distribution verification and publication.

The existing v0.13.0 release also received this compatibility feed, restoring update checks from installed v0.12.0 without a manual reinstall. Original installers, checksums and QA artifacts were preserved.

## Validation

Four focused updater tests passed, including missing/stale channel configuration, downgrade protection, unsigned consent, checksum rejection and restart safeguards. Real checksum-verified downloads of v0.13.0 passed through both the actual installed v0.12.0 service and the corrected service with channel omitted from configuration. Neither check installed software. Native package, installer and feed checks gate publication; attached QA records the build evidence.

## Known limitations

SignPath approval and signing integration remain pending. Windows updates remain unsigned and require explicit acknowledgment. macOS is not notarized; unsigned macOS and Linux retain manual upgrade paths.

## Install or upgrade

Windows v0.12.0 and v0.13.0 users can retry Settings > Updates. Download, acknowledge the unsigned release and confirm restart after saving editor changes. Portable updates open per-user setup. Other platforms use their matching native downloads.

## Integrity and source

The version tag identifies source. SHA256SUMS covers distributions and update feeds, including latest.yml; NATIVE-QA.json records native validation.
