# HRig 0.1.0 - First Windows desktop preview

## First desktop preview

- Native Windows Electron application for OpenRig, with WSL and SSH connections and live rig/seat discovery.
- Drag, split, group, float, and detach session and terminal panels. Arrange several agent sessions with the mouse.
- Native terminal support, project file browsing, Monaco editing, Git changes, messaging, task queue viewing, and saved workspace layouts.
- Connection, project, and rig contexts keep arrangements separate. Attaching a seat opens its existing session rather than starting another agent.

## Validation and source provenance

The delivery record reports six core/WSL checks and seven Electron journeys for the initial desktop baseline; live WSL discovery was confirmed by the user. This publication preserves the original executable and does not rebuild it.

The original TypeScript source was not committed. This historical tag preserves application files recovered from the original packaged app: Electron code, compiled renderer, assets, and package metadata. Third-party node_modules are omitted. See SOURCE-NOTE.md in the tag. Full editable application source begins at v0.5.0. This historical tag has its own snapshot commit and is not an empty or incorrectly versioned source tag.

## Known limitations

This first preview predates the connection doctor, bounded recovery, interactive task board, conflict-safe editing, rig designer, and later Git error fixes. Prefer the latest release for everyday use. Linux Node must be available inside WSL/SSH; a Windows npm rig shim cannot run without Linux Node.

## Install or upgrade

Download **HRig.0.1.0.exe** from this release's assets on Windows x64. Close the running HRig instance before opening the new portable executable; existing user settings remain in the HRig application-data directory. WSL or SSH hosts need Linux Node, OpenRig, tmux, and Python 3. Connect the host in HRig; this application does not install an agent harness for you.

The executable is unsigned. Windows may show a publisher warning. Only run files obtained from this private repository.

## Integrity and source

The attached **HRig-0.1.0-SHA256SUMS.txt** contains the SHA-256 digest of the executable. Check it with PowerShell: Get-FileHash -Algorithm SHA256 -LiteralPath './HRig.0.1.0.exe'. The executable is a release asset, not part of the Git source archive.
