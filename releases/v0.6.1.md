# HRig 0.6.1 - A polished rig design experience

## Redesigned rig wizard

The rig designer now has a focused, card-based layout that fits HRig's dark workspace.

- Rig Studio header with a connection badge and clear visual hierarchy.
- Numbered three-step progress indicator with completed/current states.
- Icon-based work type cards and solo/pair/team cards, including a recommended pair option.
- Keyboard-accessible radio choices with visible focus and selected states.
- Responsive agent seat cards with runtime badges, better spacing, and clearer field grouping.
- Review card showing the goal, project path, seat roster, installed agents, and runtimes.
- Compact preview success feedback and expandable specification/technical details. OpenRig warnings stay visible before launch.
- Container-based layouts adapt to narrow docked panels; reduced-motion preferences are respected.

## Release availability

Created the private GitHub repository and published all six preserved versions with detailed notes, Windows portable executables, and SHA-256 checksum files. Checked-in release notes, a version manifest, and an explicit publishing command make later releases repeatable. Historical v0.1.0 source provenance is documented separately.

## Validation

Production build and the real Electron designer journey verify needs/team/review, saved design revision, typed launch confirmation, and deletion confirmation. The journey also checks radio selections and narrow-panel overflow. Rendered screenshots cover all steps and the narrow review layout. A packaged Windows smoke test verifies the shipped runtime.

## Known limitations

The designer's launch, deletion, agent matching, and host-specific references behave as in v0.6.0. Recommendations use installed role names, not generative AI. This visual update does not add language servers, extensions, or debugging.

## Install or upgrade

Download **HRig 0.6.1.exe** from this release's assets on Windows x64. Close the running HRig instance before opening the new portable executable; existing user settings remain in the HRig application-data directory. WSL or SSH hosts need Linux Node, OpenRig, tmux, and Python 3. Connect the host in HRig; this application does not install an agent harness for you.

The executable is unsigned. Windows may show a publisher warning. Only run files obtained from this private repository.

## Integrity and source

The attached **HRig-0.6.1-SHA256SUMS.txt** contains the SHA-256 digest of the executable. Check it with PowerShell: Get-FileHash -Algorithm SHA256 -LiteralPath './HRig 0.6.1.exe'. The executable is a release asset, not part of the Git source archive.
