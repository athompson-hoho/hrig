# HRig 0.5.0 - Complete graphical workspace roadmap

## Workspace improvements

This release integrates the ten tracked improvements originally grouped under milestones 0.2 through 0.5. There were no separately packaged 0.2, 0.3, or 0.4 releases.

- Visual arranger with presets, move/split/group controls, equal sizing, and reversible layout history.
- Connection doctor for Linux Node, OpenRig, tmux, Python, authentication, and daemon availability; existing NVM initialization runs inside the connection.
- Bounded session recovery with stable seat identity and recovery of windows saved outside connected monitors.
- Attention center with evidence-based status and optional deduplicated desktop notifications.
- Role-based arrangement templates with explicit placeholders for unfilled seats.
- Interactive task board with state/owner filters, task details, assigned task creation, and owner-directed handoff requests.
- Review workspace with real Git diffs, seat context, file/line notes, and explicit feedback delivery.
- Editor improvements: external change detection, conflict-safe saves, project text search, create/rename, and diagnostics.
- Listener discovery, sandboxed app previews, and managed SSH forwarding.
- Rig manager with installed spec discovery, topology, launch planning, and typed start/restore/stop confirmation with capability checks.

## Validation

Production build, nine core/WSL checks, thirteen Electron journeys, development smoke test, packaged native-terminal/editor/doctor smoke test, and dependency audit passed in the delivery record. Destructive and messaging tests used isolated fixtures, leaving live rigs intact.

## Known limitations

Live SSH tunnels and Windows notification delivery still require deployment validation. Password-based SSH background operations, VS Code extensions, debugging, and full remote language servers are outside this release. Task queries fetch the latest 1,000 active items before filtering. External file checks run every 2.5 seconds locally or 8 seconds remotely, plus on focus. Sites can disallow embedded previews. Non-repository Git errors are fixed in v0.5.1.

## Install or upgrade

Download **HRig.0.5.0.exe** from this release's assets on Windows x64. Close the running HRig instance before opening the new portable executable; existing user settings remain in the HRig application-data directory. WSL or SSH hosts need Linux Node, OpenRig, tmux, and Python 3. Connect the host in HRig; this application does not install an agent harness for you.

The executable is unsigned. Windows may show a publisher warning. Only run files obtained from this private repository.

## Integrity and source

The attached **HRig-0.5.0-SHA256SUMS.txt** contains the SHA-256 digest of the executable. Check it with PowerShell: Get-FileHash -Algorithm SHA256 -LiteralPath './HRig.0.5.0.exe'. The executable is a release asset, not part of the Git source archive.
