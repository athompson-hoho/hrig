# HRig 0.5.2 - One-click rig project folders

## Added

Open live rig project folders without typing their paths. Press Ctrl+O or click the project card to see discovered working folders on the active WSL/SSH connection.

- Folder rows show the directory name, full path, and associated rigs.
- The selected rig's folders appear first.
- Shared folders are deduplicated while retaining all associated rig names.
- Discovery only includes tmux sessions belonging to managed OpenRig seats, excluding unrelated terminals.
- Clicking a folder validates it before switching the project and opening Explorer.
- Manual directory entry and native Windows Browse remain available.

## Validation

Production build, eleven core/WSL checks, fifteen Electron journeys, and packaged Windows smoke test passed. An isolated WSL fixture and a desktop journey verify opening a discovered folder without entering a path.

## Known limitations

Discovery reflects live pane working directories, which can change when a session changes directory. Stopped rigs have no live folder to discover. Directories are not found by recursively scanning the home folder. Existing v0.5.0 SSH, notification, and IDE limitations remain.

## Install or upgrade

Download **HRig 0.5.2.exe** from this release's assets on Windows x64. Close the running HRig instance before opening the new portable executable; existing user settings remain in the HRig application-data directory. WSL or SSH hosts need Linux Node, OpenRig, tmux, and Python 3. Connect the host in HRig; this application does not install an agent harness for you.

The executable is unsigned. Windows may show a publisher warning. Only run files obtained from this private repository.

## Integrity and source

The attached **HRig-0.5.2-SHA256SUMS.txt** contains the SHA-256 digest of the executable. Check it with PowerShell: Get-FileHash -Algorithm SHA256 -LiteralPath './HRig 0.5.2.exe'. The executable is a release asset, not part of the Git source archive.
