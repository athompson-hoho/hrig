# HRig 0.7.0 - Settings, preferences, and coordinated themes

## Settings page

Open the activity-rail gear, press Ctrl+comma, choose Settings from Tools, or find Open settings in the command center. The page docks, maximizes, and detaches like other workspace panels.

- Search 33 working preferences by label, description, category or key.
- User defaults and locally saved per-connection/project overrides, with modified indicators and a modified-only filter.
- Per-row reset and confirmed scope reset. Project reset restores inheritance from user settings.
- Validated JSON import/export and editable JSON view; invalid keys, types, ranges and oversized files are refused before applying.
- Built-in shortcut reference and About/version information. See SETTINGS.md for the full feature plan and setting catalog.

## Themes and appearance

HRig Dark, Graphite, Midnight, Daylight, High Contrast, and Follow Windows coordinate the application, docking surfaces, Monaco editors, terminal views, and detached panels. Includes mint/blue/violet/amber accents, interface fonts, compact/comfortable density, status-bar visibility and reduced motion. Existing HRig Dark colors remain the default.

## Editor and terminal

Live editor fonts, tab size and indentation, word wrap, minimap, line numbers, ligatures, whitespace, bracket coloring, and inline/side-by-side diffs. Clean-file disk reloading is configurable; unsaved edits remain protected.

Live terminal font, line height, cursor shape/blink, scrollback and independent light/dark colors update the current xterm view without restarting its PTY. Local shell defaults select PowerShell or Command Prompt for new terminals. Seat reconnection can be disabled and remains bounded when enabled. Remote agent sessions are never relaunched by settings changes.

## Recovery fix

Repeated identical terminal connection failures now trigger distinct bounded retry attempts even when React batches updates. Automatic retry still stops after six attempts; manual retry remains available.

## Workspace defaults

Configure inventory refresh frequency, new connection type/root, rig designer runtime/team size, and desktop attention notifications. The older attention notification preference is migrated. Project overrides stay in local HRig state; no project or remote settings files are written.

## Validation

Production TypeScript/Vite build, core/WSL checks, Electron workflows, live editor options, persistent scoped settings, import rejection, terminal continuity, system theme following, detached-window theming, native shell selection, screenshot review and packaged Windows smoke checks cover this release. Lifecycle tests use isolated fixtures and existing live rigs remain untouched.

## Known limitations

Fonts must be installed on this computer. Theme/profile marketplace imports, remappable shortcuts, per-language settings, cloud synchronization and an automatic updater remain follow-up ideas. Settings JSON transfers preferences, including configured default-root values, but not saved connections, credentials, layouts or terminal output. Project scope follows the active workspace. Agent permissions, provider authentication and models stay with OpenRig and the owning harness. Smaller scrollback limits can discard older visible terminal lines.

## Install or upgrade

Download **HRig.0.7.0.exe** for Windows x64. Close the running HRig instance before opening the portable executable. Existing workspace state is retained. WSL/SSH hosts still require Linux Node, OpenRig, tmux and Python 3. The executable is unsigned.

## Integrity and source

Verify the executable with **HRig-0.7.0-SHA256SUMS.txt** and PowerShell Get-FileHash -Algorithm SHA256 -LiteralPath './HRig.0.7.0.exe'. Source and full documentation are available under this release tag; the executable is an attached release asset.
