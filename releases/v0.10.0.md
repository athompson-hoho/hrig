# HRig 0.10.0 - Terminal search and output tools

## New

- Find retained terminal output with Ctrl+F/Cmd+F, case sensitivity, regular expressions, match highlights and previous/next navigation.
- Enter and Shift+Enter navigate matches. Escape returns focus to the terminal and restores the previous scroll position.
- Copy selected text or all retained output, and export a plain-text snapshot through a native save dialog.
- Open HTTP/HTTPS links after native confirmation, and open project file links in the editor using the originating terminal's host and project.

## Reliability and boundaries

- Search input never becomes a shell command. Terminal tools preserve the existing shell and agent session.
- Invalid regexes, export cancellation and write failures have visible outcomes. Highlight counts are capped and labeled at 1,000 matches.
- Plain-text output omits escape/control sequences and rejoins soft-wrapped lines. Only retained active-buffer output is available; this is not continuous session recording.
- File links retain backend project confinement and file-size limits. This version detects conventional unwrapped paths with extensions; paths containing whitespace are not detected. Relative paths resolve against the attached project root.
- Browser links allow only HTTP/HTTPS without embedded credentials; opening requires explicit confirmation.

## Validation

The release workflow gates all five native OS/architecture builds on backend tests, production compilation, packaged terminal/editor/recovery checks, architecture-specific feed hashes, distribution verification and performance reports. Windows also exercises installation, installed-app smoke, uninstall and settings preservation. Published NATIVE-QA.json records exact source and results. Desktop terminal-tool checks exercise a real disposable Windows shell, search/case/regex navigation, clipboard, export/cancel, clickable project links, browser-link confirmation and session continuity.

## Install or upgrade

Windows x64: assisted per-user setup or portable EXE. macOS Apple Silicon/Intel: DMG or ZIP. Linux x64/ARM64: AppImage, tar.gz, DEB or RPM. Download the matching asset and use the combined SHA256SUMS file to verify it.

Signing credentials remain deferred. Downloads are unsigned and macOS is not notarized. Settings > Updates checks stable releases and opens manual downloads; automatic installation remains disabled. Existing settings, layouts and recoverable drafts are retained by the upgrade path. OpenRig owns agents and their permissions.

## Integrity and source

The version tag identifies the immutable release source. The combined checksum file covers distribution/update assets; NATIVE-QA.json includes matching source, native runtime checks, packaging policy and performance evidence. Full terminal behavior and limitations are documented in TERMINALS.md.
